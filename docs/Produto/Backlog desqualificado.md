#### Despesas em custo de vida

Criar uma forma de identificar se uma despesa é custo de vida.

Custo de vida é tudo que dificilmente é possível cortar caso seja necessário reajustar o orçamento doméstico. São coisas com o Supermercado, Lazer, Saúde, Educação e outros identificadores nesse sentido.

Ter uma definição de custo de vida, permite criar visualizações específicas a respeito. Mais ou menos eu faço isso quando gero o relatório mensal, onde eu removo da conta identificadores relacionados a compras e outros para entender mais ou menos o gasto fixo do mês.
