# RF 01.02.02 - Filtro por data

__Descrição__
Permitir aos usuários filtrarem na tabela de registros pelos campos disponíveis.

__Impacto__
Ter a opção de filtrar os dados, pode permitir aos usuários encontrarem dados para corrigi-los, por exemplo.
