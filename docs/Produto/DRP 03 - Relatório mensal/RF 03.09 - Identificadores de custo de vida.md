# RF 03.09 - Identificadores de custo de vida

__Descrição__
Como usuário quero ter uma visão específica dos registros identificados como custo de vida.

__Impacto__
O custo de vida é algo que geralmente não altera entre os meses. Ter uma visão específica desse tipo nos permite entender o básico para manter a vida que temos.

#### Critérios de aceite

**Cenário:** Identificadores de custo de vida
- **Dado** que um identificador é definido como parte do custo de vida
- **Então** ele deve ser exibido destacado
