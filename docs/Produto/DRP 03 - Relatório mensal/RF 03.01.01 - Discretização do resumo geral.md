# RF 03.01.01 - Discretização do resumo geral

__Descrição__
Como usuário quero ver todas os registros que montam o relatório mensal a fim verificar cada entrada.

__Impacto__

#### Critérios de aceite

**Cenário:** Exibição do registros
- **Dado** que estou no Relatório mensal com um mês selecionado
- **Quando** seleciono para exibir o relatório
- **Então** é aberto uma modal com todos os dados que definem o relatório

**Cenário:** Edição de registros
- **Dado** que estou na exibição dos dados do resumo geral
- **Quando** seleciono para editar uma informação do registro (Nome, Valor, Identificação)
- **Então** o registro e atualizado
- **E** o relatório é atualizado
