## Modal de conferência de importação de extratos

![[Modal de conferência de importação de Extratos.png|%]]

Coisas que gostaria de adicionar

- Nome do arquivo importado
- No botão de confirmação ter o número de registros importados
- Formato de abas entre Novas entradas, Registros duplicados, Regras aplicadas
- Aba de de Regras aplicadas, ter essa explicação pode ajudar o usuário a entender o que está acontecendo
    - Regras para identificação
    - Regras para duplicados

Coisas que não quero

- Paginação
- Modo de seleção de novas entradas, o usuário pode remover essas entradas
