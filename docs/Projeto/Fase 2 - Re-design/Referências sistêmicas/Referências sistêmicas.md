# Referências sistêmicas

As referências sistêmicas foram construídas a fim de auxiliar no processo de implementação das funcionalidades, recursos e sistemas da [[Fase 2 - Re-design]]

## Temas

Para os temas será construído um sistema de gerenciamento de tema entre claro e escuro, utilizando como base [[app.theme.dart]].

O arquivo [[theme_sample_use_cases.dart]] apresenta alguns casos de uso para a aplicação. É importante essas **decisões de design sejam modularizadas**, a fim de agilizar o processo de desenvolvimento e permitir modificações futuras com baixo esforço.
